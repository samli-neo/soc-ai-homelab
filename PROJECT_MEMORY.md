## 17. Common Patterns / Gotchas

### PowerShell quoting with plink
- Prefer environment variables for passwords, e.g. `-pw $env:PROXMOX_SSH_PASS`.
- If a literal password contains `$`, PowerShell double quotes expand it; use single quotes or environment variables.
- For nested commands in plink, use single-quoted strings (PowerShell won't expand `$` inside single quotes)
- For complex scripts, write to a `.sh` file, pscp it, then execute via pct exec

### pct exec quoting
- `pct exec 200 -- COMMAND` — the command after `--` is passed directly
- Nested shell with `$()` or `||` often fails — use script files instead
- `pct exec 200 -- sh -c "..."` works but `$` variables get expanded by outer shell

### Docker container restart vs reload
- Bind-mounted config files: changes take effect on `docker restart` (not `docker exec nginx -s reload` for bind-mounted nginx configs that changed structure)
- For cert replacement on bind-mounted files: replace source file + `docker restart` container
- For cert replacement on Docker volumes (like misp-certs): `docker cp` new cert into container + `docker exec nginx -s reload`

### Playwright pfSense session
- Session at `pfsense-storage-state.json` expires after ~1 hour
- Re-authenticate: navigate to `https://10.10.50.254/`, fill login form, save storage state
- pfSense cert forms: `#method` select, `#descr` input, `#caref` select, `#dn_commonname`, `#type` select, SANs via `#addrow` + `#altname_typeN`/`#altname_valueN`
- Cert refid lookup: use `diag_command.php` with PHP `simplexml_load_file("/cf/conf/config.xml")`
